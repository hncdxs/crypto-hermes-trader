# Crypto AI Trader Frontend

React 前端，提供 Web UI 管理界面。

## 目录结构

```
frontend/
├── src/
│   ├── pages/           # 页面
│   │   ├── Init.tsx     # 项目初始化
│   │   ├── Strategies.tsx
│   │   ├── Traders.tsx
│   │   └── Dashboard.tsx
│   ├── components/      # 通用组件
│   ├── plugins/         # 前端插件注册
│   │   └── plugin_registry.ts
│   └── App.tsx
├── public/
├── Dockerfile
├── package.json
└── nginx.conf
```
